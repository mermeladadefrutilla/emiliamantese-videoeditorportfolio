PORTFOLIO AUDIOVISUAL — paquete listo para usar

Cómo abrirlo:
1. Descomprimí el archivo ZIP.
2. Abrí index.html en tu navegador.
3. Para publicarlo online, subí toda la carpeta a un hosting, Netlify, Vercel, GitHub Pages o similar.

Qué incluye:
- index.html: página web del portfolio.
- assets/videos: copias comprimidas de tus videos para web.
- assets/thumbs: thumbnails/posters.
- assets/videos/00_showreel_base_sin_musica.mp4: showreel base de aproximadamente 49 segundos.

Pendientes para personalizar:
- Reemplazar “Portfolio Audiovisual” por tu nombre o marca personal.
- Completar tu mail, Instagram, WhatsApp o link de contacto.
- Ajustar el rol real de cada proyecto: cámara, edición, dirección, guion, color, motion, etc.
- Agregar música al showreel base y ajustar cortes finos si querés usarlo como reel final.
